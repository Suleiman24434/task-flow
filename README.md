# TaskFlow 📝

A sleek, lightning-fast daily planner and task management web application built with vanilla JavaScript, featuring seamless browser data persistence via `localStorage`.

## 🎯 The Problem It Intends to Solve

Managing daily goals shouldn't require bloated, slow apps or internet connectivity. Many students, developers, and remote workers struggle with disorganization because traditional task apps are overly complex or lose data the moment the browser tab refreshes. 

TaskFlow solves this by providing a clean, distraction-free environment that instantly saves user tasks locally in the browser, ensuring productivity data is preserved across sessions without needing a backend server database.

---

## 🚀 Essential Features

* **Data Persistence (`localStorage`):** Automatically saves your tasks locally so they don't disappear when you refresh or close your browser.
* **Interactive Task Filtering:** Seamlessly switch between **All**, **Active**, and **Completed** views to stay focused.
* **Dynamic Counter & Batch Clearing:** Real-time tracking of remaining tasks, plus a one-click "Clear Completed" button to clean up finished work.
* **Responsive & Accessible Design:** Built with modern CSS Flexbox and Grid, optimizing performance across mobile phones, tablets, and desktop computers.

---

## 🔮 Future Features Roadmap

Planned upgrades for future versions of TaskFlow include:
1. **Due Dates & Priority Tags:** Adding color-coded priority levels (High, Medium, Low) and specific deadlines for tasks.
2. **Category Workspaces:** Grouping tasks into separate boards like *Work*, *Personal*, and *Learning*.
3. **Dark Mode Toggle:** A built-in dark theme toggle for late-night coding sessions.
4. **Cloud Sync:** Connecting to a user authentication service (like Firebase) to sync tasks across multiple devices.
